Rune Statistics

Rune counts are saved whenever changed manually (i.e., entering a number or using increment/decrement buttons). These values should persist even when this page is closed. To clear saved runes click Reset Runes then adjust a rune up/down.

Statistics collected for 10-300 rune drops by multinomial random number generation 1e6 times for each number of rune drops, then fitted to Generalized Extreme Value (GEV) distribution. Probabilities derived from treasureclassex.txt and assume all runes capable of dropping. Not intended for use beyond 1 Zod equivalent of rune value.
